## `wf-nmr-aggregate`

- **Step:** `nmr_aggregate`
- **Module:** `scripps_workflow.nodes.nmr_aggregate`

Boltzmann-averaged ¹H/¹³C chemical shifts and ¹H-¹H coupling predictions over a conformer ensemble. Consumes a ``thermo_aggregate`` upstream and emits CSVs, mnova-spinsim XMLs (pre-averaged + per-conformer), and 2D/3D molecule diagrams annotated with predicted shifts.

### Config keys

#### Section: general

#### `solvent`

- **Type:** `str`
- **Default:** `"CHCl3"`

Solvent name (used for calibration table lookup and embedded in artifact metadata). SMD aliases are resolved per ``orca.solvent_to_orca_smd``.

#### Section: shielding

#### `shielding_method_h`

- **Type:** `str`
- **Default:** `"WP04"`

DFT functional label for ¹H shielding calibration lookup. ``WP04`` is cheshire's recommended choice (Wiitala/Hoye/Cramer 2006).

#### `shielding_basis_h`

- **Type:** `str`
- **Default:** `"6-311++G(2d,p)"`

Basis set for ¹H shielding calibration lookup.

#### `shielding_method_c`

- **Type:** `str`
- **Default:** `"wB97X-D"`

DFT functional for ¹³C shielding calibration lookup. ``wB97X-D`` is cheshire's default.

#### `shielding_basis_c`

- **Type:** `str`
- **Default:** `"6-31G(d,p)"`

Basis set for ¹³C shielding calibration lookup.

#### Section: coupling

#### `coupling_method`

- **Type:** `str`
- **Default:** `"mPW1PW91"`

DFT functional for J-coupling calibration lookup. ``mPW1PW91`` is the cheshire / Bally-Rablen default.

#### `coupling_basis`

- **Type:** `str`
- **Default:** `"pcJ-2"`

Basis set for J-coupling calibration lookup.

#### `skip_couplings`

- **Type:** `bool`
- **Default:** `False`

If true, skip parsing the ``orca_nmr_j.out`` files and emit only chemical-shift CSVs / XMLs. Useful when the upstream didn't run coupling jobs.

#### Section: outputs

#### `output_shifts_csv`

- **Type:** `str`
- **Default:** `"predicted_shifts.csv"`

Basename for the predicted-shifts CSV.

#### `output_couplings_csv`

- **Type:** `str`
- **Default:** `"predicted_couplings.csv"`

Basename for the predicted-couplings CSV.

#### Section: mnova

#### `smiles`

- **Type:** `str`
- **Default:** `None`
- **Related:** `mnova_enabled`, `diagrams_enabled`

Canonical SMILES. Drives the equivalence detector for both mnova XML and diagram emission. When absent, the aggregator falls back to xyz perception of any conformer's geometry; if that also fails, XML and diagrams are skipped with ``mnova_xml_skipped:topology_unavailable``.

#### `mnova_enabled`

- **Type:** `bool`
- **Default:** `True`

Master toggle for mnova-spinsim XML emission.

#### `mnova_per_conformer`

- **Type:** `bool`
- **Default:** `True`

Also emit ``predicted_mnova_<nuc>_per_conformer.xml`` files (one ``<spin-system>`` per conformer with the Boltzmann weight as ``<population>``).

#### `mnova_nuclei`

- **Type:** `str`
- **Default:** `"1H,13C"`
- **Choices:** `1H`, `13C`, `1H,13C`, `13C,1H`

Comma-separated list of nuclei to emit XML files for. Tokens: ``1H``, ``13C``.

#### `mnova_field_mhz_h`

- **Type:** `float`
- **Default:** `600.15`

¹H Larmor frequency (MHz). Default targets a 600 MHz spectrometer.

#### `mnova_field_mhz_c`

- **Type:** `float`
- **Default:** `150.94`

¹³C Larmor frequency (MHz).

#### `mnova_line_width_hz_h`

- **Type:** `float`
- **Default:** `1.0`
- **Min:** `0.0`

Simulated peak linewidth (Hz) in ¹H spectra.

#### `mnova_line_width_hz_c`

- **Type:** `float`
- **Default:** `5.0`
- **Min:** `0.0`

Simulated peak linewidth (Hz) in ¹³C spectra. Broader by default to reflect broadband-decoupled ¹³C peak appearance.

#### `mnova_from_ppm_h`

- **Type:** `float`
- **Default:** `0.0`

Lower edge of the simulated ¹H spectrum (ppm).

#### `mnova_to_ppm_h`

- **Type:** `float`
- **Default:** `12.0`

Upper edge of the simulated ¹H spectrum (ppm).

#### `mnova_from_ppm_c`

- **Type:** `float`
- **Default:** `0.0`

Lower edge of the simulated ¹³C spectrum (ppm).

#### `mnova_to_ppm_c`

- **Type:** `float`
- **Default:** `220.0`

Upper edge of the simulated ¹³C spectrum (ppm).

#### `mnova_points`

- **Type:** `int`
- **Default:** `16384`
- **Min:** `64`

FID points in the simulated spectrum. Higher = finer resolution but slower mnova render.

#### `mnova_tol_jcoupling_hz`

- **Type:** `float`
- **Default:** `0.5`
- **Min:** `0.0`

Magnetic-equivalence J-vector tolerance (Hz). Topological classes whose member J-vectors agree to within this are classified HARD; mismatches → SOFT (AA'BB' patterns).

#### `mnova_tol_shift_ppm`

- **Type:** `float`
- **Default:** `0.05`
- **Min:** `0.0`

Data-aware refinement tolerance (ppm). Within a topological class in a chiral molecule, members whose DFT shifts spread above this get split into NONE singletons (catches diastereotopic CH₂).

#### `mnova_j_round_threshold_hz`

- **Type:** `float`
- **Default:** `0.25`
- **Min:** `0.0`

Predicted |J| at or below this threshold gets rounded to 0 before emission. Removes near-zero long-range coupling noise. Set to 0 to disable.

#### `mnova_heteronuclear_partners`

- **Type:** `csv`
- **Default:** `[]`
- **Related:** `smiles`

Additional elements (e.g., ``F``, ``P``) to include as groups in EVERY primary-nucleus spin-system XML. Required for ¹H-¹⁹F coupling to render in the ¹H spectrum. Must coordinate with ``orca_thermo_array.coupling_pairs`` so ORCA actually computes the cross-element J's.

#### `mnova_partner_shift_stub_ppm`

- **Type:** `float`
- **Default:** `100.0`

Placeholder shift (ppm) for partner-element atoms whose σ wasn't parsed. Lands them outside typical primary-nucleus windows so the J-driven splitting on the primary spectrum is what shows.

#### Section: diagrams

#### `diagrams_enabled`

- **Type:** `bool`
- **Default:** `True`

Toggle for ``predicted_structure_<nuc>.svg`` and ``.html`` diagram artifacts. Reuses ``mnova_nuclei`` to pick which nuclei to depict.

#### `diagrams_width`

- **Type:** `int`
- **Default:** `900`
- **Min:** `100`

Diagram canvas width (px).

#### `diagrams_height`

- **Type:** `int`
- **Default:** `600`
- **Min:** `100`

Diagram canvas height (px).

## `wf-thermo-aggregate`

- **Step:** `thermo_aggregate`
- **Module:** `scripps_workflow.nodes.thermo_aggregate`

Composite-Gibbs aggregator over an upstream freq+SP conformer array. Emits one CSV with absolute / relative energies, Boltzmann weights, and cumulative-weight columns. Composite protocol: ``G_composite = E_SP_high + (G - E_el)_low``, with a fallback to ``G_low`` when no high-level SP energy is available.

### Config keys

#### `temperature_k`

- **Type:** `float`
- **Default:** `298.15`

Temperature (K) for the Boltzmann reweighting and the standard-state correction. Matches ORCA's own default. Must be strictly positive.

#### `standard_state`

- **Type:** `str`
- **Default:** `"1atm"`
- **Choices:** `1atm`, `1m`, `1mol`, `1molar`

Standard-state convention. ``1atm`` (default) keeps ΔG referenced to the gas-phase 1 atm convention. Any of ``1m``/``1mol``/``1molar`` applies the Ben-Naim RT·ln(24.46) shift to the relative ΔG column.

#### `output_csv`

- **Type:** `str`
- **Default:** `"conformer_thermo.csv"`

Basename of the per-conformer CSV written to ``outputs/`` in the call directory.

#### `n_tasks_override`

- **Type:** `int`
- **Default:** `0`
- **Aliases:** `n_tasks`
- **Min:** `0`

Override the n_tasks count taken from the upstream manifest. ``0`` (default) means use the upstream value. Positive values truncate or extend the walk. Legacy argv token ``n_tasks=`` is accepted as an alias so old workflow JSONs keep working.
