## `wf-crest`

- **Step:** `crest`
- **Module:** `scripps_workflow.nodes.crest`

Chain node — runs CREST conformer search on the first ``.xyz`` artifact from upstream. Emits a conformer ensemble (one xyz per conformer) plus the CREST log files. Defaults to iMTD-GC at GFN2-XTB.

### Config keys

#### `theory`

- **Type:** `str`
- **Default:** `"GFN2-XTB"`

xTB theory level CREST uses internally. See ``_THEORY_ALIASES`` for case-insensitive aliases.

#### `charge`

- **Type:** `int`
- **Default:** `0`

Molecular charge passed to CREST.

#### `unpaired_electrons`

- **Type:** `int`
- **Default:** `0`
- **Min:** `0`

Unpaired electrons (CREST's ``--uhf``).

#### `solvent`

- **Type:** `str`
- **Default:** `None`

ALPB solvent name. ``none``/``null``/``vacuum`` / empty → vacuum. See ``ALPB_SOLVENTS``.

#### `mode`

- **Type:** `str`
- **Default:** `"standard"`

CREST search mode. ``standard`` (default) = iMTD-GC. See ``CREST_MODES`` for the supported tokens.

#### `ewin_kcal`

- **Type:** `float`
- **Default:** `10.0`

Energy window (kcal/mol) above the lowest-energy conformer that CREST retains. Must be strictly positive.

#### `max_conformers`

- **Type:** `int`
- **Default:** `0`
- **Min:** `0`

Cap on the number of conformers retained from CREST's ensemble. ``0`` (default) means no cap — keep everything inside the energy window.

#### `threads`

- **Type:** `int`
- **Default:** `0`
- **Min:** `0`

Threads passed to CREST (``-T``). ``0`` auto-detects from SLURM if available, else 1.

#### `use_cache`

- **Type:** `bool`
- **Default:** `True`

Consult the nmr-data ConformerEnsemble cache on entry. On hit, skip the CREST run entirely and emit a manifest pointing at the central-tree xyz files. Set to false to always re-run.

#### `force_recompute`

- **Type:** `bool`
- **Default:** `False`

Force a fresh CREST run even when the cache would hit. Useful when investigating non-determinism or after upgrading CREST. The cache row from the prior run stays in the DB; the new compute output gets a new predicted_run UUID at db_ingest time.

## `wf-marc-screen`

- **Step:** `marc_screen`
- **Module:** `scripps_workflow.nodes.marc_screen`

Chain node — clusters a conformer ensemble via navicat-marc (rotation-corrected RMSD with optional moment-of-inertia augmentation). Pruning typically follows a CREST or prism_screen ensemble; representatives feed the downstream DFT array.

### Config keys

#### `min_conformers`

- **Type:** `int`
- **Default:** `3`
- **Min:** `1`

Minimum input ensemble size before marc clustering is attempted; smaller ensembles are passed through unchanged.

#### `metric`

- **Type:** `str`
- **Default:** `"mix"`

Distance metric for clustering. Aliases: ``rmsd``/``rmsd_pruning`` → rmsd; ``moi``/``moi_pruning`` → moi; ``rotcorr``/various → rotcorr_rmsd; ``mix``/``auto`` → mix (default).

#### `clustering`

- **Type:** `str`
- **Default:** `"auto"`

Clustering algorithm token. ``auto`` (default) lets marc choose; see ``_ALLOWED_CLUSTERINGS`` for the explicit set.

#### `n_clusters`

- **Type:** `json`
- **Default:** `None`

Target number of clusters. ``auto`` / empty / unset → None (marc decides). Otherwise a positive int.

#### `use_energies`

- **Type:** `str`
- **Default:** `"auto"`

Whether marc weights cluster centroids by relative energies. ``true``/``false``/``auto`` (default — use energies if available).

#### `ewin_kcal`

- **Type:** `float`
- **Default:** `5.0`
- **Min:** `0.0`

Pre-clustering energy window (kcal/mol) above the lowest-energy conformer; conformers above the window are dropped before marc runs.

#### `timeout_s`

- **Type:** `int`
- **Default:** `120`
- **Min:** `5`

Wall-clock cap for the marc subprocess. Marc can hang on pathological inputs; this is the safety valve.

#### `keep_rejected`

- **Type:** `bool`
- **Default:** `True`

Whether to keep rejected (non-representative) conformer xyz files in the artifact bucket for inspection. Disable to save disk.

Basis set for ¹³C shielding calibration lookup.

Basename for the predicted-couplings CSV.

Canonical SMILES. Drives the equivalence detector for both mnova XML and diagram emission. When absent, the aggregator falls back to xyz perception of any conformer's geometry; if that also fails, XML and diagrams are skipped with ``mnova_xml_skipped:topology_unavailable``.

Master toggle for mnova-spinsim XML emission.

#### `mnova_per_conformer`

Comma-separated list of nuclei to emit XML files for. Tokens: ``1H``, ``13C``.

¹H Larmor frequency (MHz). Default targets a 600 MHz spectrometer.

¹³C Larmor frequency (MHz).

Simulated peak linewidth (Hz) in ¹H spectra.

#### `mnova_line_width_hz_c`

- **Type:** `float`
- **Default:** `5.0`
- **Min:** `0.0`

Simulated peak linewidth (Hz) in ¹³C spectra. Broader by default to reflect broadband-decoupled ¹³C peak appearance.

#### `mnova_from_ppm_h`

Lower edge of the simulated ¹H spectrum (ppm).

Upper edge of the simulated ¹H spectrum (ppm).

#### `mnova_from_ppm_c`

- **Type:** `float`
- **Default:** `0.0`

Lower edge of the simulated ¹³C spectrum (ppm).

#### `mnova_to_ppm_c`

- **Type:** `float`
- **Default:** `220.0`

Upper edge of the simulated ¹³C spectrum (ppm).

#### `mnova_points`

- **Type:** `int`
- **Default:** `16384`
- **Min:** `64`

FID points in the simulated spectrum. Higher = finer resolution but slower mnova render.

#### `mnova_tol_jcoupling_hz`

- **Type:** `float`
- **Default:** `0.5`
- **Min:** `0.0`

Magnetic-equivalence J-vector tolerance (Hz). Topological classes whose member J-vectors agree to within this are classified HARD; mismatches → SOFT (AA'BB' patterns).

#### `mnova_tol_shift_ppm`

- **Type:** `float`
- **Default:** `0.05`
- **Min:** `0.0`

Data-aware refinement tolerance (ppm). Within a topological class in a chiral molecule, members whose DFT shifts spread above this get split into NONE singletons (catches diastereotopic CH₂).

#### `mnova_j_round_threshold_hz`

- **Type:** `float`
- **Default:** `0.25`
- **Min:** `0.0`

Predicted |J| at or below this threshold gets rounded to 0 before emission. Removes near-zero long-range coupling noise. Set to 0 to disable.

#### `mnova_heteronuclear_partners`

- **Type:** `csv`
- **Default:** `[]`
- **Related:** `smiles`

Additional elements (e.g., ``F``, ``P``) to include as groups in EVERY primary-nucleus spin-system XML. Required for ¹H-¹⁹F coupling to render in the ¹H spectrum. Must coordinate with ``orca_thermo_array.coupling_pairs`` so ORCA actually computes the cross-element J's.

#### `mnova_partner_shift_stub_ppm`

- **Type:** `float`
- **Default:** `100.0`

Placeholder shift (ppm) for partner-element atoms whose σ wasn't parsed. Lands them outside typical primary-nucleus windows so the J-driven splitting on the primary spectrum is what shows.

#### `auto_heteronuclear`

- **Type:** `bool`
- **Default:** `True`

When true (default), scan upstream conformer xyz files for ¹⁹F and ³¹P and auto-add the matching symbols to ``mnova_heteronuclear_partners`` if they aren't already there. Pairs with the same-named knob on ``orca_thermo_array`` so the ORCA J's and the mnova XML stay in sync without operator action. Set to false to force the {¹⁹F} / {³¹P} decoupled-spectrum view: only operator-supplied partners are emitted.

#### Section: diagrams

#### `diagrams_enabled`

- **Type:** `bool`
- **Default:** `True`

Toggle for ``predicted_structure_<nuc>.svg`` and ``.html`` diagram artifacts. Reuses ``mnova_nuclei`` to pick which nuclei to depict.

#### `diagrams_width`

- **Type:** `int`
- **Default:** `900`
- **Min:** `100`

Diagram canvas width (px).

#### `diagrams_height`

- **Type:** `int`
- **Default:** `600`
- **Min:** `100`

Diagram canvas height (px).

## `wf-orca-dft-array`

- **Step:** `orca_dft_array`
- **Module:** `scripps_workflow.nodes.orca_dft_array`

SLURM-array DFT geometry optimizer. Walks an upstream conformer ensemble, writes one ORCA input per conformer, submits as a SLURM job array, and (optionally) blocks on completion. Emits per-task ``orca.out`` plus a consolidated manifest with parsed final energies.

### Config keys

#### `max_concurrency`

- **Type:** `int`
- **Default:** `10`
- **Aliases:** `max_nodes`, `batchsize`

``%M`` for SLURM ``--array=1-N%M`` — at most this many array tasks run concurrently. Aliases ``max_nodes``/``batchsize`` accepted for back-compat. Garbage values silently fall back to ``10``; values below 1 are clamped to 1.

#### `charge`

- **Type:** `int`
- **Default:** `0`

Molecular charge.

#### `unpaired_electrons`

- **Type:** `int`
- **Default:** `0`
- **Min:** `0`

Unpaired electrons (used to compute multiplicity).

#### `multiplicity`

- **Type:** `json`
- **Default:** `None`

Explicit spin multiplicity override. ``None`` / ``auto`` / empty → computed as ``unpaired_electrons + 1`` (DFT) or ``2 * unpaired_electrons + 1`` (GOAT).

#### `solvent`

- **Type:** `str`
- **Default:** `None`

Implicit-solvent name (CPCM token). ``none``/``null``/``auto`` / empty → vacuum.

#### `smd_solvent`

- **Type:** `str`
- **Default:** `None`

SMD solvent name (gets passed as ``CPCM(SMD,<name>)``). Mutually independent of ``solvent``.

#### `keywords`

- **Type:** `str`
- **Default:** `"r2scan-3c TightSCF TightOpt"`

ORCA simple-input line for the primary calculation. Whitespace-stripped.

#### `maxcore`

- **Type:** `int`
- **Default:** `4000`

Per-process memory budget (MB) passed via ``%maxcore``. Values below ``500`` are silently clamped up — ORCA crashes below ~500MB on most non-trivial systems.

#### `nprocs`

- **Type:** `int`
- **Default:** `8`

OpenMPI processes per ORCA task (``%pal nprocs``). Values below 1 are silently clamped to 1.

#### `time_limit`

- **Type:** `str`
- **Default:** `"12:00:00"`

SLURM ``--time=`` value. ``HH:MM:SS`` or ``D-HH:MM``.

#### `partition`

- **Type:** `str`
- **Default:** `None`

SLURM partition name. ``None`` / ``auto`` / empty → cluster default.

#### `job_name`

- **Type:** `str`
- **Default:** `None`

SLURM job-name prefix. ``None`` → auto-derived from the workflow step name.

#### `orca_module`

- **Type:** `str`
- **Default:** `"orca/6.0.0"`

Lmod module name ``module load``-ed inside the per-task wrapper.

#### `submit`

- **Type:** `bool`
- **Default:** `True`

If false, write the SLURM script + per-task input files but skip ``sbatch``. Useful for dry-run inspection.

#### `monitor`

- **Type:** `bool`
- **Default:** `True`

If true, the node blocks on the array job and watches per-task progress; if false, ``sbatch`` and exit immediately.

#### `monitor_interval_s`

- **Type:** `int`
- **Default:** `60`

Seconds between progress polls when ``monitor=true``. Values below 5 are clamped to 5.

#### `monitor_timeout_min`

- **Type:** `int`
- **Default:** `0`

Wall-clock cap on the monitor loop. ``0`` (default) = no cap, wait forever.

#### `silence_openib`

- **Type:** `bool`
- **Default:** `True`

Set ``OMPI_MCA_btl=^openib`` to silence the verbose Infiniband warnings on the Scripps cluster.

#### `use_cache`

- **Type:** `bool`
- **Default:** `True`

Consult the nmr-data DftRun cache on entry. On hit, skip the SLURM DFT-opt array entirely — emit a manifest pointing at the parent ensemble's central-tree optimized xyzs so downstream nodes (orca_thermo_array etc.) see the geometries as if this node had just produced them. Set to false to always re-run.

#### `force_recompute`

- **Type:** `bool`
- **Default:** `False`

Force a fresh DFT-opt array even when the cache would hit. Useful when investigating ORCA non-determinism or after an ORCA version bump that should change the optimized geometries.

Consult the nmr-data ThermoRun + PredictedRun caches on entry. On hit, skip the whole SLURM array — decompress central-tree .out files into a local task_dir tree so thermo_aggregate + nmr_aggregate downstream walk them transparently. Set to false to always re-run the freq+SP and NMR jobs.

#### `force_recompute`

- **Type:** `bool`
- **Default:** `False`

Force a fresh SLURM array submission even when the cache would hit. Useful when investigating ORCA non-determinism or after a functional-alias bug fix that should change the values written to the database.

Basis set for the ¹³C shielding job.

Basis set for the J-coupling job.

#### `coupling_pairs`

- **Type:** `csv`
- **Default:** `['all H']`
- **Related:** `run_couplings`

ORCA nuclei selectors for the J-coupling block. Accepts either a list (JSON config) or comma-separated string (key=value config). Tokens are ORCA-syntax (e.g. ``"all H"``, ``"1, 4, 7"``, ``"all C"``). Must be non-empty when ``run_couplings=true``.

- **Type:** `float`

- **Type:** `str`

- **Type:** `bool`

When true (default), scan the upstream geometry for ¹⁹F and ³¹P; append ``"all F"`` / ``"all P"`` to ``coupling_pairs`` so the ORCA J-coupling job computes the cross-element couplings needed for the H/C simulated spectra to show realistic heteronuclear splitting (¹H-¹⁹F, ¹³C-³¹P, etc.). #### `system_class`

- **Type:** `str`
- **Default:** `"auto"`

Chemistry class profile for the NMR shielding + coupling jobs. ``auto`` scans the input geometry for heavy-element triggers and picks the matching profile (currently: Pd -> 'organopd', else 'organic'). ## `wf-thermo-aggregate`

- **Step:** `thermo_aggregate`
- **Module:** `scripps_workflow.nodes.thermo_aggregate`

Composite-Gibbs aggregator over an upstream freq+SP conformer array. Emits one CSV with absolute / relative energies, Boltzmann weights, and cumulative-weight columns. Composite protocol: ``G_composite = E_SP_high + (G - E_el)_low``, with a fallback to ``G_low`` when no high-level SP energy is available.

### Config keys

#### `temperature_k`

- **Type:** `float`
- **Default:** `298.15`

Temperature (K) for the Boltzmann reweighting and the standard-state correction. Matches ORCA's own default. Must be strictly positive.

#### `standard_state`

- **Type:** `str`
- **Default:** `"1m"`
- **Choices:** `1atm`, `1m`, `1mol`, `1molar`

Standard-state convention. ``1atm`` (default) keeps ΔG referenced to the gas-phase 1 atm convention. Any of ``1m``/``1mol``/``1molar`` applies the Ben-Naim RT·ln(24.46) shift to the relative ΔG column.

#### `output_csv`

- **Type:** `str`
- **Default:** `"conformer_thermo.csv"`

Basename of the per-conformer CSV written to ``outputs/`` in the call directory.

#### `n_tasks_override`

- **Type:** `int`
- **Default:** `0`
- **Aliases:** `n_tasks`
- **Min:** `0`

Override the n_tasks count taken from the upstream manifest. ``0`` (default) means use the upstream value. Positive values truncate or extend the walk. Legacy argv token ``n_tasks=`` is accepted as an alias so old workflow JSONs keep working.

## `wf-xtb`

- **Step:** `xtb_calc`
- **Module:** `scripps_workflow.nodes.xtb_calc`

Chain node — runs one or more xTB operations (optimize, sp_energy, sp_gradient, sp_hessian) on the first ``.xyz`` artifact from the upstream node. Emits per-op subdirectories plus a consolidated ``wf.result.v1`` manifest with parsed energies / gradient norm / hessian summary.

### Config keys

#### `theory`

- **Type:** `str`
- **Default:** `"GFN2-XTB"`
- **Choices:** `GFN-FF`, `GFN1-XTB`, `GFN2-XTB`

xTB theory level. Aliases (case-insensitive): ``GFN2`` / ``GFN2-XTB`` / ``GFN2XTB`` → GFN2-XTB; ``GFN1`` / ``GFN1-XTB`` → GFN1-XTB; ``GFN-FF`` / ``GFNFF`` / ``GFF`` → GFN-FF.

#### `charge`

- **Type:** `int`
- **Default:** `0`

Molecular charge (passed to xtb via --chrg).

#### `unpaired_electrons`

- **Type:** `int`
- **Default:** `0`
- **Min:** `0`

Number of unpaired electrons (passed to xtb via --uhf). 0 = closed-shell singlet.

#### `solvent`

- **Type:** `str`
- **Default:** `None`

ALPB solvent name. ``none``/``null``/``vacuum`` and empty string all map to vacuum (no implicit solvent). See ``ALPB_SOLVENTS`` for the supported list.

#### `opt_level`

- **Type:** `str`
- **Default:** `"tight"`

xTB geometry-optimization convergence level. See ``OPT_LEVELS`` for the supported tokens (e.g. ``crude``/``loose``/``normal``/``tight``/``vtight``/``extreme``).

#### `calculations`

- **Type:** `json`
- **Default:** `['optimize']`

Which xTB operations to run, in canonical order. Accepts a list, CSV string, single token, or a JSON object using GUI labels as keys (e.g. ``{"SP Energy": true, "Geometry Optimization": true}``). Tokens: ``optimize``, ``sp_energy``, ``sp_gradient``, ``sp_hessian``.

#### `threads`

- **Type:** `int`
- **Default:** `0`
- **Min:** `0`

OMP_NUM_THREADS for the xtb process. ``0`` (default) means auto-detect from the SLURM allocation if available, else 1.

#### `write_json`

- **Type:** `bool`
- **Default:** `True`

Whether xtb should emit ``xtbout.json`` alongside the text ``xtb.out``. Disable to save disk for large screening sweeps.
